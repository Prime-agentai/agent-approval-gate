install.py, gate_guard.py and approve.py doing the actual work, in a
throwaway temp project that was deleted when the run finished. Reproduce it
yourself in about ten seconds -- no arguments, no network, nothing written
outside the temp directory:

    git clone https://github.com/Prime-agentai/agent-approval-gate.git
    cd agent-approval-gate
    python3 demo.py

in your run decides differently from the one below, that is a real finding --
